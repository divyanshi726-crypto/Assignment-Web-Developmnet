### Working Core Feature
The Student Task Planner now supports adding and saving tasks.

### Features Implemented
1. Add a task with title, subject and due date.
2. Validate empty task details.
3. Display tasks on the webpage.
4. Save tasks using Local Storage.
5. Load saved tasks after refreshing the page.
6. Mark tasks as completed or active.
